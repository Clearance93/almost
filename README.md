# Almost

**The party game of near-miss words.** Everyone gets the same secret word — except one player, who
gets its nearest neighbour in meaning. Describe, accuse, and then watch the reveal show exactly how
close the two words were.

Built for the [Appwrite Databases Hackathon](https://hackathon.appwrite.io), October 2026.

> Status: in active development. The round engine, word deck, design system, and landing page are
> in place; the playable table is landing next.

## How it works

Each word in the deck is stored once in **Appwrite VectorsDB** as a 768-dimension embedding,
generated by Appwrite's built-in `nomic-embed-text` model. A round is built with a similarity search:

```ts
Query.vectorCosine("embeddings", secretVector)
Query.limit(40)
```

The results come back ranked by cosine distance (`$distance`, closest first). The server keeps the
neighbours inside the current spice band and deals one as the odd player's word. Close enough to
bluff, far enough to get caught.

## Local development

```bash
npm install
cp .env.example .env.local   # fill in endpoint, project id, API key
npm run seed                 # embed the deck, create the HNSW index
npm run dev
```

`npm run check-db` verifies connectivity and prints a live similarity search.
`npm run calibrate` prints distance samples for tuning the difficulty bands.

The API key is only ever read on the server. No `NEXT_PUBLIC_` secrets.
