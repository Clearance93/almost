# Almost — build plan

> A party game where the odd player's word is the **nearest neighbour** of the real word in
> vector space. Built solo for the Appwrite Databases Hackathon (Oct 19–31, 2026).

### Scoring map — how we win each criterion

| Criterion | Our answer | Where judges see it |
|---|---|---|
| **Idea & innovation** | Word games hand-write their decks. Almost *generates* every decoy from embedding space, so difficulty is a continuous dial and the deck never runs out. | Landing page headline, 20s of the video, the reveal |
| **Technical execution** | Typed round engine, deterministic seeds, server-only API keys, HNSW index, calibrated bands, graceful fallbacks. | Repo structure, README, it simply doesn't break live |
| **Design & experience** | Editorial "survey map" identity, pass-the-phone deal flow, a dramatic dark reveal with the meaning map. No AI-purple gradients. | Every screen; especially the reveal |
| **Usage of Appwrite Databases** | VectorsDB is the *game engine*, not storage: built-in embeddings, `vectorCosine` search, `$distance` as a game rule, metadata filters, HNSW. | Architecture section, the query shown on screen at 1:35 |

**The one-sentence pitch:** *Almost is a social deduction game whose deck is generated by vector
search — the impostor's word is the closest word in meaning to everyone else's, and the reveal shows
you exactly how close it was.*

## Architecture

```
Browser (Next.js client)
  │  no API key, no direct writes for game state
  ▼
Next.js route handlers (server)
  │  node-appwrite, APPWRITE_API_KEY
  ├─ Embeddings API    text → 768d vector (nomic-embed-text)
  └─ VectorsDB         nearest-neighbour search + $distance
```

- The decoy is never stored in the client bundle.
- The client never learns the roles until the reveal response.
- Every round is reproducible from its seed (good for debugging and for the video).

## Risks and fallbacks

| Risk | Mitigation |
|---|---|
| VectorsDB not selectable on a Free org | Fall back to **Managed PostgreSQL + pgvector** — still one of the five allowed databases, and arguably a stronger technical story. Only the data layer changes (`lib/vector-store.ts`). |
| Embedding API rate limits while seeding | Batch 25 texts/request, checkpoint to `data/cache/embeddings.json`, resume on failure. Seed once. |
| Bad decoys (synonyms, nonsense) | `TOO_CLOSE` guard, calibrated bands, `npm run calibrate`, curated word list, manual spot-check of 50 pairs. |
| Scope creep into online multiplayer | Pass-and-play is the shipped mode. Rooms are a stretch goal only after M2 is green. |
| Demo video rambles | Scripted beats, recorded in one take per beat, captions burned in. |

## Explicit non-goals

- Accounts, friends lists, chat, matchmaking.
- Native apps.
- Custom embedding models.
- Monetisation.
